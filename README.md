# chongmindev.github.io

Personal site for Chong Min, live at <https://chongmindev.github.io/>.

A single static page (`index.html`, inline CSS and JS, Google Fonts) served by GitHub Pages
from `main`. No build step: edit `index.html`, push, and Pages redeploys.

- `index.html`: bio, experience, and projects
- `404.html`: not found page served by GitHub Pages
- `images/`: portrait and favicon

Preview locally with `python3 -m http.server` and open <http://localhost:8000>.
